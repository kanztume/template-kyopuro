# template-kyopuro
競技プログラミングで使用する自分用のC++などのテンプレートリポジトリです。

## リポジトリ構成
- `cpp-template` : C++のテンプレートを保存するフォルダ
  - ｀normal-template.cpp` : コンテスト本番で使用するC++基本テンプレートコード
- `README.md` : 参考リンクおよび運用規約・ライセンス情報の管理

├── README.md               # 本ドキュメント（構成案内・参考URL）
├── template.cpp            # 本番提出用の基本テンプレート
└── library/                # 自作・検証済みライブラリ用フォルダ
    ├── math.cpp            # 数学系アルゴリズム（gcd, 二分探索など）
    └── data_structure.cpp  # データ構造系（累積和、map補助関数など）
